# Nazar GM — Portfolio

Interactive 3D Game Developer & Software Engineer Portfolio. Built with React, Three.js (@react-three/fiber), TypeScript, Express, and Supabase.

## Features
- **Interactive 3D Scene**: Character model with animations and rotation controls
- **Dynamic Panels**: About, Experience, Projects, Skills (progress bars), and Achievements
- **Admin Dashboard**: Secure management of portfolio content
- **Multi-language Support**: English and Indonesian (i18n)
- **Responsive Layout**: Optimized for desktop and mobile devices

## Tech Stack
- **Frontend**: Vite, React, TypeScript, Tailwind/CSS, Three.js, Lucide Icons
- **Backend**: Express, TypeScript, Supabase (PostgreSQL + Storage)
- **Deployment**: Vercel
